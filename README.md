# 🕵️ Infiltrado

**Infiltrado** é um jogo social de dedução desenvolvido para navegador, em que os participantes precisam descobrir quem está escondendo sua verdadeira identidade.

O jogo foi pensado para partidas presenciais, permitindo que os jogadores utilizem o mesmo dispositivo para receber seus papéis e participar das rodadas.

## 🎮 Funcionalidades

- Partidas de 4 a 12 jogadores.
- Configuração de 1 a 3 infiltrados.
- Nove categorias de palavras.
- Sistema de revelação individual de papéis.
- Rodadas com pistas e votação.
- Temporizador opcional.
- Sistema de pontuação.
- Interface disponível em português e inglês.
- Efeitos sonoros e configurações personalizáveis.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Extraia os arquivos, caso tenha baixado o ZIP.
3. Abra o arquivo `index.html` em um navegador.

O projeto não exige instalação de dependências nem configuração de servidor para sua execução básica.

## 📂 Estrutura do projeto

- `index.html` — Estrutura da interface.
- `style.css` — Estilização e responsividade.
- `script.js` — Lógica e funcionamento do jogo.
- `i18n.js` — Internacionalização.
- `data/` — Categorias e bancos de palavras.

## 📌 Sobre o projeto

O Infiltrado foi desenvolvido para explorar lógica de programação, manipulação do DOM, gerenciamento de estados e construção de interfaces interativas utilizando JavaScript.
